# GeoAI Portfolio

Twelve one-week projects that build up from software foundations to a full GeoAI application. Each project is a
small, finished MVP in its own repository, with tests, documentation and a written record of the design
decisions behind it.

**Focus:** Geospatial Data Science and GeoAI, backed by data engineering.
**Home city for the data:** Seattle.

## How each project is documented

Every repository has the same structure:

- `README.md`: what it does and how to run it
- `docs/PLAN.md`: scope, validation criteria and the definition of done
- `docs/DECISIONS.md`: each design choice, why it was made, and what was rejected
- `docs/JOURNAL.md`: the build log, step by step

## How these were built

Developed with AI pair-programming (Claude Code); design decisions documented in each project's `docs/`.
